DISCIPLINE QUEST V4

V4 adds: player profile/name, four themes, optional completion sound, JSON backup/restore, CSV statistics export, and Stop & Claim for partial task completion. It retains the existing localStorage key disciplineQuest.v1 so V1/V2/V3 progress remains on the same browser installation.

UPDATE YOUR EXISTING GITHUB PAGES REPOSITORY
1. Download and extract this ZIP.
2. Open your existing Discipline-quest repository in Chrome.
3. Upload all five files to the repository root, replacing the previous versions.
4. Commit the changes to the main branch.
5. Wait for GitHub Pages deployment to complete.
6. Close and reopen the installed app. If the old version remains, open the site in Chrome and refresh once.

IMPORTANT
- Do not clear browser/site data or uninstall the app during the update.
- Download a backup from Data Vault after updating.
- Restoring a backup replaces the current local app data.
- CSV export contains completed mission records available in the app.
- All data remains on this device unless you manually export and store a backup.
- Sound and visual themes are optional.

STOP & CLAIM
- While a mission timer is running or paused, use STOP & CLAIM to close the mission early.
- Crowns and XP are awarded proportionally to focused time, rounded down to whole points.
- The mission is marked PARTIAL and closed for that day; it will not roll over.
- RESET restarts the timer and clears the current session focus time.


V4.1 UPDATE: Independent Mission Timers
Each mission now saves its own timer progress. Switching to another mission automatically pauses and stores the previous mission, including focused time and remaining time. Return to that mission and press RESUME to continue. Existing V4.1 Stop & Claim remains available.
